# 报告解读

回测报告页由四个部分组成，帮助你全面评估策略表现。

## 1. 指标卡

页面顶部展示 6 个核心指标：

- **总收益**（红色✚绿色▼）：总盈亏比例，涨红跌绿（中国股市惯例）
- **年化收益**：按实际交易日年化，便于跨周期比较
- **最大回撤**：从净值最高点到后续最低点的跌幅，衡量极端风险
- **夏普比率**：风险调整后收益，一般 >1 算不错，>2 算优秀
- **胜率**：盈利交易次数 / 总交易次数
- **Alpha / Beta**：相对基准的超额收益和系统性风险敞口

## 2. 净值曲线

图表包含三个元素：

- **蓝色线**：策略净值（初始资金归一化为 1）
- **灰色虚线**：基准指数净值
- **红色阴影**：回撤区间（净值从高点回落的幅度）

可以直接对比策略 vs 基准的表现：

- 蓝线持续高于灰线 → 策略产生 Alpha
- 红色阴影面积大 → 回撤严重，需关注风控

## 3. 月度收益热力

表格展示每个月度的收益：

- 红底表示正收益（盈利月）
- 绿底表示负收益（亏损月）
- 可以快速判断策略的月度胜率和季节性特征

## 4. 成交明细

列出回测期间的每一笔交易：

| 列 | 说明 |
|----|------|
| 日期 | 成交日期 |
| 标的 | 股票/ETF/基金代码 |
| 方向 | 买入/卖出 |
| 数量 | 成交数量（股/份） |
| 价格 | 成交价（前复权） |
| 金额 | 成交金额 |
| 费用 | 佣金+印花税+滑点成本 |

## 理解回测局限性

回测结果优美不代表实盘能复现：

1. **幸存者偏差**：回测使用的是当前仍在交易的股票
2. **流动性假设**：假设所有订单都能按理论价格成交
3. **成本简化**：只计算了佣金和印花税，未考虑冲击成本
4. **过拟合风险**：历史完美拟合的策略可能在未来失效

建议：

- 在多个时间窗口和不同标的上测试
- 关注回撤和夏普，不要只看总收益
- 参数数量越少越好（奥卡姆剃刀）
- 模拟交易是回测到实盘之间的必要验证环节
