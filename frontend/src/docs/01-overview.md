# 平台概览

trading-quant 是一个个人量化交易平台，让你在网页端编写策略、一键回测、浏览绩效报告、运行模拟交易。

## 核心功能

| 模块 | 功能 |
|------|------|
| **策略编辑** | 浏览器内 Python 编辑器 + 自动参数表单 |
| **历史回测** | 日线数据回测，2010 年至今 A 股全覆盖 |
| **绩效报告** | 净值曲线、回撤分析、夏普比率、月度收益热力 |
| **模拟交易** | 虚拟账户每日自动推进，验证策略实盘表现 |

## 工作流程

1. **写策略**：在策略编辑器里用 Python 写策略逻辑（继承 `Strategy` 基类）
2. **跑回测**：配置回测区间和成本参数，一键运行
3. **看报告**：净值曲线、绩效指标、成交明细一页展示
4. **模拟运行**：将验证过的策略部署到模拟账户，每日自动推进

## 技术架构

```
前端 (React + Monaco + ECharts)
    ↓ REST / WebSocket
后端 (FastAPI + SQLAlchemy)
    ↓
引擎 (事件驱动回测 / 模拟交易同构)
    ↓
数据层 (DuckDB 日线行情 + SQLite 业务数据)
```

## 数据覆盖

- **品种**：A 股股票、场内 ETF、场外公募基金
- **频率**：日线（架构预留分钟级扩展）
- **范围**：2010 年 7 月至今
- **数据源**：tushare Pro 为主，每日收盘后增量同步
